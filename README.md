### 🏆 Các Dự Án & Giải Pháp Nổi Bật (Featured Projects)

#### 1. 🌐 Kiếm Seo — High-Performance Traffic & SEO Platform
> Nền tảng SaaS tăng trưởng traffic thật và tối ưu hóa thứ hạng SEO chuẩn Google Analytics 4.
- **Tech Stack:** Next.js 14, TypeScript, Tailwind CSS, PostgreSQL, Prisma ORM, Linux VPS, Nginx, PM2.
- **Điểm nhấn:**
  - Đạt điểm chuẩn hiệu năng **100/100 Google Lighthouse** trên cả thiết bị di động và máy tính.
  - Cơ chế lọc bot ảo & click fraud thông minh đạt tỷ lệ hợp lệ **99.82%**.
  - Pipeline tự động hóa triển khai **Zero-Downtime Deployment** với cơ chế Atomic Swap và tự phục hồi (Health Check Rollback).

#### 2. 🛡️ Multi-Layer Application Hardening & Anti-Tamper Engine
> Hệ thống phòng thủ mã nguồn 5 tầng bảo vệ runtime logic và ngăn chặn can thiệp trái phép.
- **Tech Stack:** JavaScript/TypeScript, WebAssembly (WASM), Cloudflare Workers, Cryptography.
- **Điểm nhấn:**
  - **5-Layer Architecture:** Phân tách token qua Edge Worker, làm rối luồng logic (Control Flow Flattening), mã hóa chuỗi RC4.
  - **Runtime Integrity & Anti-Debug:** Bẫy phát hiện DevTools, đo lường độ trễ thực thi (`performance.now()`), chuyển sang chế độ **Silent Failure** khi bị can thiệp.
  - **Memory Zero-Trace:** Xử lý luồng nhị phân trong buffer RAM cô lập, tự hủy dấu vết ngay sau khi xử lý.

#### 3. ⚡ High-Concurrency Network & Automation Engine
> Bộ công cụ xử lý mạng đa luồng tốc độ cao dành cho phân phối tác vụ quy mô lớn.
- **Tech Stack:** Golang, Goroutines, Channels, Python, SQLite.
- **Điểm nhấn:**
  - Xử lý hàng chục nghìn kết nối đồng thời với mức tiêu thụ tài nguyên tối thiểu.
  - Tích hợp hệ thống xoay vòng Proxy thông minh và module nhận diện/giải mã Captcha tự động.

#### 4. 🔍 Reverse Engineering & Security Lab
> Nghiên cứu bảo mật, phân tích giao thức mạng và tự động hóa quy trình kiểm thử xâm nhập.
- **Tech Stack:** Burp Suite, CTF Sandbox Orchestrator, Linux, Security Auditing.
- **Điểm nhấn:** Phân tích mã độc/mã bị làm rối (Deobfuscation), kiểm thử an toàn theo chuẩn OWASP Top 10.
